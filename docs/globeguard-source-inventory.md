## Product and service map

- GlobeGuard BASIC: focused OBD diagnostic sets for one selected manufacturer group.
- GlobeGuard PRO: broader, expandable diagnostic sets for mixed vehicle coverage.
- Software updates: compatibility updates and manufacturer group extensions.
- Services: remote diagnostics and Security Gateway Stellantis support.
- Accessories: adapter cables for Sprinter/VW LT, truck MB, Iveco SGW, KTM, and TRUMA Combi heaters.
- Support: update software, remote diagnostics configuration, quick-start documents, adapter instructions, VAG FAQ, flyer, DiagCenter setup, and mobile apps.
- Partner workshops: published support network includes Switzerland, Chile, Germany, and Czech Republic.
